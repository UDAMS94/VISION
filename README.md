# VISION 클래스 – 온라인 강의 사이트

21일 · 66일 · 100일 과정의 온라인 강의 사이트입니다. HTML, CSS, JavaScript만으로 만들어 별도 빌드나 서버 프로그램 없이 동작합니다.
반응형이라 모바일에서도 볼 수 있고, **PWA**(설치형 웹앱)라서 휴대폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈: 메인 배너, 과정 소개(21/66/100일), 유튜브 영상, 강사 소개, FAQ |
| `course.html?id=21` | 과정 상세: 소개, 커리큘럼(단계별 일차 목록), 수강 시작 |
| `watch.html?id=21&day=1` | 강의 시청: YouTube 플레이어, 오늘의 미션, 메모, 완료 체크, 강의 목록 |
| `my.html` | 내 강의실: 진도율, 연속 학습일, 일차별 완료 현황 |

## 내용 바꾸기: `js/data.js`만 수정하면 됩니다

- **사이트 정보**: `SITE.name`, `tagline`, `instructor`(강사 소개), `contact`
- **유튜브 채널 영상**: `SITE.youtube.channelUrl`(채널 주소), `featured`(홈에 보일 영상)
- **강의 영상**: 각 과정의 `lessons`에 일차별로 입력합니다.

```js
lessons: {
  1: { title: "오리엔테이션", videoId: "XXXXXXXXXXX", duration: "12:00", mission: "오늘의 미션" },
  2: { ... },
}
```

`videoId`는 유튜브 주소 `https://www.youtube.com/watch?v=XXXXXXXXXXX`에서 `v=` 뒤에 있는 11자리입니다.
입력하지 않은 일차에는 "N일차 강의"라는 기본 제목과 "영상 준비 중" 화면이 표시됩니다.

- **강의 잠금 방식**: `SITE.unlockMode`
  - `"sequential"`: 이전 강의를 완료해야 다음 강의가 열림 (기본값)
  - `"daily"`: 수강을 시작한 날부터 하루에 한 강씩 열림
  - `"all"`: 모든 강의가 열림

## 내 컴퓨터에서 실행하기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 더블클릭해서 열어도 화면은 보이지만, 앱 설치(서비스 워커) 기능은 `http(s)://` 주소에서만 동작합니다.

## 배포하기 (예: GitHub Pages)

1. 이 저장소를 GitHub에 push합니다.
2. GitHub 저장소 → **Settings → Pages** → Branch에서 배포할 브랜치와 `/ (root)`를 선택합니다.
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.

Netlify, Vercel, Cloudflare Pages 같은 정적 호스팅에 폴더를 그대로 올려도 됩니다.

> 사이트 파일을 수정해 다시 배포할 때는 `sw.js`의 `CACHE = "vision-v1"` 숫자를 올려주세요. 그래야 앱으로 설치한 사용자에게도 새 내용이 반영됩니다.

## 앱으로 만들기

1. **PWA (지금 바로 가능)**: HTTPS로 배포한 뒤
   - Android Chrome: 메뉴 → "앱 설치", 또는 상단의 "📲 앱 설치" 버튼
   - iPhone Safari: 공유 버튼 → "홈 화면에 추가"
2. **앱스토어 · 플레이스토어 등록 (다음 단계)**: 배포한 PWA를 [PWABuilder](https://www.pwabuilder.com/)로 스토어용 패키지로 만들거나, [Capacitor](https://capacitorjs.com/)로 감싸서 네이티브 앱으로 빌드하는 방법이 있습니다. 스토어마다 개발자 계정, 심사 기준, 수수료 정책이 따로 있으니 등록 전에 각 스토어의 최신 정책을 확인하세요.

## 꼭 알아두세요 (현재 버전의 한계)

- **로그인 · 결제 기능이 없습니다.** "수강 시작하기"를 누르면 누구나 바로 수강할 수 있습니다. 유료로 판매하려면 회원 관리와 결제 기능(예: Firebase/Supabase 같은 백엔드 + 토스페이먼츠·포트원 같은 결제 서비스)을 붙여야 합니다. `js/app.js`의 `// TODO: 결제 연동` 부분이 연결 위치입니다.
- **학습 기록은 기기별로 저장됩니다.** 진도와 메모는 브라우저 localStorage에 저장되므로 다른 기기나 브라우저에서는 이어지지 않고, 브라우저 데이터를 지우면 함께 사라집니다.
- **유튜브 영상 보안**: 강의 영상을 유튜브 "일부 공개"로 올리면 검색에는 나오지 않지만, 주소(영상 ID)를 아는 사람은 누구나 볼 수 있습니다. 이 사이트의 잠금 기능은 화면에서 막아줄 뿐이라 영상 ID는 페이지 소스에서 보입니다. 유료 강의 영상을 확실히 보호하려면 Vimeo의 도메인 제한이나 전용 영상 호스팅(예: 결제·로그인과 연동되는 VOD 서비스)을 검토하세요.
